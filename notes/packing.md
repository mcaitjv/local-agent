# 🎒 Weekend Trip Packing List

**Trip Duration:** 3 days (Saturday through Monday)  
**Weather Assumption:** Moderate/indoor travel - adjust for your destination  
**Travel Style:** Casual / Comfortable  

---

## 👕 Clothing

- [ ] T-shirts: 2-3 (short and long sleeve mix)
- [ ] Bottoms: 1 pair (jeans/trousers) + 1 casual shorts/pants option
- [ ] Underwear: 4 pairs
- [ ] Socks: 4 pairs
- [ ] Sleepwear: 1 set
- [ ] Shoes: Comfortable walking shoes + optional extra pair for evenings
- [ ] Sweater/Jacket: 1 (weather-dependent)
- [ ] Belt/scarf/hat: As needed

## 🧴 Toiletries & Personal Items

- [ ] Toothbrush + toothpaste
- [ ] Deodorant
- [ ] Skincare basics (face wash, moisturizer, sunscreen)
- [ ] Hair care items
- [ ] Razor + shaving supplies
- [ ] Medications (prescriptions, pain relievers, first aid)
- [ ] Eyeglasses/contact lenses + solution

## 🔌 Electronics

- [ ] Phone + charger
- [ ] Power bank/battery pack
- [ ] Headphones/earbuds
- [ ] Camera (optional)
- [ ] Portable laptop/tablet with charger (if needed)

## 📄 Documents & Essentials

- [ ] ID/Passport/License
- [ ] Credit/debit cards + cash ($100-$200)
- [ ] Reservation confirmations (tickets, booking refs)
- [ ] Travel insurance info
- [ ] Notebook + pen (or phone notes ready)
- [ ] Keys

## 🧰 Miscellaneous

- [ ] Reusable water bottle
- [ ] Laundry bag/dry bag
- [ ] Ziplock bags for organization
- [ ] Small backpack/day pack for outings
- [ ] Snacks/energy bar (optional)
- [ ] Umbrella or travel poncho (if needed)

---

## 📋 Packing Tips

1. Roll clothes to save space and minimize wrinkles
2. Pack a day bag separately from luggage
3. Leave room in suitcase for souvenirs
4. Check hotel amenities before packing (towels, toiletries, etc.)
5. Set an alarm to check out time!
